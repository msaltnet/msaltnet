# 읽기 쉬운 타이포그래피 설계

## 목표

사이트 전반의 작은 텍스트가 더 편하게 읽히도록 기본 글자와 보조 텍스트를 15~20% 확대한다.

## 설계

- 본문 기본 크기는 `1rem`을 유지하고 줄 간격을 `1.75`로 조정해 과도한 전체 확대를 피한다.
- 사이드바 인용문, 개인 메모, 프로젝트 카드, 메뉴, 라벨, 날짜 등 작은 텍스트를 선택적으로 확대한다.
- 히어로와 섹션 제목, 이미지 크기, 카드 높이는 유지한다.
- 프로젝트 카드의 작은 라벨은 `0.72rem`, 제목은 `0.9rem`, 설명은 `0.78rem`으로 조정해 카드 안에서 읽히도록 한다.
- 모바일에서는 작은 메뉴 텍스트도 동일한 가독성 기준을 적용하되 기존 레이아웃과 줄바꿈을 보존한다.

## 검증

- 기존 Python 및 Playwright 테스트를 실행한다.
- 데스크톱과 모바일 렌더링에서 카드 넘침, 수평 스크롤, 과도한 줄바꿈이 없는지 확인한다.
