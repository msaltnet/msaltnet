# Home Share Thumbnail Design

## Goal

Restore the large image preview shown when sharing `https://msalt.net/` by using the existing home hero image at `/assets/img/hero-bg.jpg`.

## Root Cause

The previous site declared `og:image` and `twitter:image` directly in `index.html`. After the redesign, metadata is generated by `jekyll-seo-tag`, but the configured default image applies only to posts. The home page has no `image` front matter, so its generated HTML omits both image metadata fields and falls back to a small `summary` Twitter card.

## Design

Add `image: /assets/img/hero-bg.jpg` to the home page front matter. Keep metadata generation centralized in the existing `{% seo %}` tag rather than adding hand-written tags or broadening the image default to every page.

The resulting home page must contain:

- an absolute `og:image` URL pointing to `https://msalt.net/assets/img/hero-bg.jpg`;
- an absolute `twitter:image` URL pointing to the same image;
- `twitter:card` set to `summary_large_image`.

Post behavior remains unchanged: posts without their own image continue to inherit the existing post default.

## Verification

Add an automated regression test that builds the Jekyll site and inspects the generated home page metadata. The test must fail before the front-matter change and pass afterward. Run the focused test and the full existing test suite, then build the site once more to confirm generated output.

## Non-goals

- Creating a new social-card image.
- Adding per-post share images.
- Hand-writing duplicate Open Graph or Twitter tags.
- Changing crawler cache behavior on external sharing platforms.
