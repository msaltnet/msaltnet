# 본문 외부 링크 동작 설계

## 목표

게시글 본문에서 외부 링크는 새 탭으로 열고, 본문 안의 모든 링크는 밑줄로 구분한다.

## 범위

- 대상은 게시글 레이아웃의 `.post-content` 안에 렌더링된 링크다.
- `http://` 또는 `https://` URL로 시작하는 외부 링크에만 `target="_blank"`와 `rel="noopener noreferrer"`를 추가한다.
- 상대 경로, 앵커 링크, 동일 사이트 링크는 현재 탭에서 연다.
- 메뉴, 목록, 프로젝트 카드 등 본문 밖의 링크 스타일과 동작은 바꾸지 않는다.

## 구현

- 게시글 레이아웃에서 로드되는 JavaScript가 `.post-content a`를 순회한다.
- 외부 URL 링크만 식별해 새 탭 및 보안 속성을 설정한다. 이미 작성된 속성은 덮어쓴다.
- 스타일시트에 `.post-content a` 규칙을 추가해 밑줄을 보이게 한다.

## 검증

- 생성된 게시글 HTML에서 외부 링크가 `target="_blank"`와 `rel="noopener noreferrer"`를 받는지 확인한다.
- 내부 링크는 이 속성을 받지 않는지 확인한다.
- 브라우저 테스트에서 본문 링크의 밑줄 스타일과 외부 링크 동작을 확인한다.
