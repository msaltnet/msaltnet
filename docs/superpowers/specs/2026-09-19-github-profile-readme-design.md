# GitHub 프로필 README 설계

## 목표

GitHub 프로필에서 맛소금의 일, 개인 프로젝트, 글쓰기를 친근한 한·영 소개로 전달한다.

## 대상과 톤

- 개인 프로젝트와 글을 함께 보고 싶은 GitHub 방문자를 대상으로 한다.
- 전문성은 드러내되, 과장된 이력서 문체 대신 편안하고 사람다운 문장으로 쓴다.

## 구성

1. 이름과 짧은 한국어 인사
2. AX와 소프트웨어 엔지니어링을 하는 현재의 일 소개
3. 자동매매 시스템, AI·라즈베리파이 비서, Tizen 로그 뷰어, 책과 글을 담은 대표 활동 목록
4. 웹사이트·블로그·브런치 링크
5. 같은 정보를 자연스러운 영어로 쓴 별도 섹션

## 범위

- `README.md`의 소개 문구만 교체한다.
- 기술 배지, 활동 통계, 자동 생성 콘텐츠는 추가하지 않는다.
- 프로젝트의 소스 코드나 사이트 콘텐츠는 변경하지 않는다.

## 검증

- Markdown 제목과 한·영 섹션을 확인한다.
- 모든 소개 링크가 의도한 주소를 가리키는지 확인한다.
- 기존 작업과 무관한 파일을 포함하지 않고 변경사항을 검토한다.
